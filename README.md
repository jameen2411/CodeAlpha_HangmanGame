# 🎯 Hangman Game (Python)

A simple terminal-based Hangman game built using Python. The player guesses letters to uncover a hidden word before running out of lives.

---

## 🧠 Features

- Random word selection (from a fixed list)
- Interactive letter guessing system
- Life-based gameplay (6 chances)
- Real-time word progress display
- Win/Lose detection

---

## 📂 Word List

The game currently includes these words:

- banana
- kivi
- mango
- grape

---

## 🚀 How to Run

1. Make sure Python is installed (Python 3+ recommended)
2. Download or clone this repository
3. Run the script:

```bash
python hangman.py
